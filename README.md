# Приглашение на прогулку ♡

Небольшой интерактивный сайт: открываешь конверт, отвечаешь на вопрос и выбираешь дату и время. Подтверждение приходит владельцу сайта в Telegram.

Проект можно скопировать и настроить под себя. Здесь только исходники: токена бота, ID чата и настроек чужого аккаунта нет.

## Что внутри

- Конверт с печатью и анимацией открытия.
- Плавающие сердечки и нарисованные SVG-котики.
- Кнопка «Нет» убегает от мыши или касания. На шестую попытку она становится «Да» на последнем месте; обе кнопки открывают форму. Первая «Да» увеличивается максимум на 30%.
- Розовый календарь и выбор времени с шагом в пять минут.
- Выбор только будущего времени в ближайшие 14 суток, с проверкой в браузере и на сервере.
- Сообщение в Telegram с датой, временем и часовым поясом посетителя.
- Адаптация под телефон и поддержка настройки уменьшения анимаций.

## Устройство проекта

```text
index.html            HTML, CSS, JavaScript и SVG-рисунки
api/invite.js         серверная функция Node.js для Vercel
server.py             локальный сервер на Python
.env.example          пустой шаблон настроек
vercel.json           настройки сборки и функции
package.json          команда сборки
tools/get-chat-id.py  помощник для получения ID чата
```

Внешних библиотек и базы данных нет. Бот не нуждается в постоянно запущенной программе: сервер вызывает Telegram Bot API при подтверждении формы. Секреты остаются на сервере.

## 1. Создать своего бота

1. Открой [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправь `/newbot`, выбери имя и username нового бота.
3. Сохрани выданный токен. Не добавляй его в HTML или публичный репозиторий.
4. Открой своего нового бота, нажми **Старт** и отправь любое сообщение. Это нужно сделать с аккаунта, на который ты хочешь получать уведомления.
5. Получи свой ID чата:

```sh
python3tools/get-chat-id.py
```

На Windows можно использовать `py` вместо `python3`. Помощник запросит токен скрытым вводом и покажет ID личных чатов из последних сообщений. Выбери ID своего чата. Он не сохраняет токен и не отправляет сообщений.

Если список пуст, отправь боту ещё одно сообщение и запусти помощник снова. Используй отдельного нового бота: если другой сервис уже получает его обновления или установлен webhook, `getUpdates` может не вернуть сообщения. Помощник не отключает webhook и не меняет настройки бота.

Официальные инструкции: [создание бота](https://core.telegram.org/bots/tutorial#obtain-your-bot-token), [getUpdates](https://core.telegram.org/bots/api#getupdates).

## 2. Запустить локально

Нужен Python 3.10 или новее. Скачай ZIP репозитория через **Code → Download ZIP** и распакуй либо клонируй репозиторий. Открой терминал в его папке.

Скопируй `.env.example` в `.env`:

```sh
# macOS / Linux
cp .env.example .env
```

```powershell
# Windows PowerShell
Copy-Item .env.example .env
```

Открой `.env` редактором и вставь свои значения:

```dotenv
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN
TELEGRAM_CHAT_ID=YOUR_CHAT_ID
PORT=8017
```

Запусти сервер:

```sh
python3 server.py
```

Открой **http://127.0.0.1:8017/**. Для Windows: `py server.py`.

Без настроек можно посмотреть интерфейс; отправка в Telegram будет недоступна. Чтобы проверить весь сценарий, выбери будущие дату и время, подтверди и проверь сообщение в своём Telegram. Надпись «Договорились, жду ❤️» появляется только после успешного ответа Telegram.

Сервер также принимает переменные окружения; они имеют приоритет над `.env`. После изменения настроек перезапусти сервер. Если порт занят, поменяй `PORT` и адрес в браузере.

Локальный Python-сервер предназначен для просмотра на своём компьютере и слушает только `127.0.0.1`. Простое открытие `index.html` или GitHub Pages покажет интерфейс, но не обеспечит отправку: для неё необходим серверный обработчик `/api/invite`.

## 3. Опубликовать на Vercel

1. Скопируй проект в свой GitHub через **Use this template** (если включено владельцем) или **Fork**.
2. В Vercel выбери **Add New → Project**, импортируй свой репозиторий.
3. Оставь корнем проекта папку репозитория. Framework Preset — **Other**. Настройки из `vercel.json`: Build Command — `npm run build`, Output Directory — `public`.
4. В настройках проекта добавь серверные Environment Variables:

| Имя | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен твоего бота |
| `TELEGRAM_CHAT_ID` | ID твоего личного чата с ботом |

Выбери окружение **Production**. Если хочешь проверять отправку на Preview-ссылках, добавь значения и для **Preview**. `PORT` на Vercel не нужен. Не используй публичные префиксы вроде `NEXT_PUBLIC_` для токена.

5. Нажми **Deploy**. После изменения переменных потребуется новая публикация (**Redeploy**).
6. Открой выданную HTTPS-ссылку и проверь отправку. Если ссылка требует входа в Vercel, проверь настройки Deployment Protection перед тем, как делиться ей.

Для сборки используется Node.js 22 или новее. Команда копирует исходный `index.html` в `public`; Vercel отдельно публикует `api/invite.js` как серверную функцию.

Документация: [переменные окружения Vercel](https://vercel.com/docs/environment-variables).

## Настроить под себя

Редактируй исходный `index.html`, а не сгенерированный `public/index.html`.

| Что изменить | Где искать |
| --- | --- |
| Заголовок вкладки | `<title>` |
| Вопрос | `id="question-title"` |
| Текст формы | `id="schedule-title"` |
| Финальное сообщение | `id="success-title"` |
| Розовые цвета и оформление | блок `<style>`, `:root` и правила `background` |
| Рисунки котиков | `<svg>` внутри кнопок `yes-button` и `no-button` |
| Поведение «Нет» | функция `runAway`, переменная `escapeCount` |
| Сердечки | функция `burstHearts` и анимации в CSS |
| Сообщение в Telegram | `text` в `api/invite.js` и `server.py` |

**Период выбора:** сейчас это следующие 14 × 24 часа от текущего момента, включая сегодня, если время ещё не прошло. Дата и время показываются в часовом поясе устройства посетителя; этот пояс приходит в уведомлении. На последнем дне доступны только часы в пределах этого периода.

Чтобы изменить период, синхронно замени ограничение `14` в проверках даты/времени и соответствующих сообщениях в `index.html`, `api/invite.js` и `server.py`. Не меняй все числа `14` подряд: часть из них — размеры в CSS.

## Если что-то не работает

- **Отправка не настроена:** проверь обе переменные на сервере; для Vercel — нужное окружение и новый Deploy.
- **Сообщение не приходит:** нажми Старт у своего бота, проверь токен и ID чата, убедись, что бот не заблокирован. Сначала проверь Telegram перед повторной отправкой: сетевой сбой может произойти уже после доставки.
- **Дата не подтверждается:** проверь часы и часовой пояс устройства. Время должно быть в будущем и в пределах 14 суток.
- **Ошибка Origin:** открывай сайт по его адресу, а не через сторонний HTML-просмотрщик или iframe с другого домена.
- **Vercel не публикует:** проверь авторизацию, лимиты аккаунта и журнал сборки проекта.

## Ограничения

Это личное приглашение по ссылке. Форма не определяет личность посетителя: тот, кому доступна ссылка, может отправить заявку, в том числе повторно. Проверка Origin не заменяет защиту от спама. Для широкой публичной аудитории добавь ограничение частоты запросов или проверку доступа.

Настоящие `.env`, папка `.vercel` и результаты сборки исключены из Git. Если токен случайно опубликован, перевыпусти его через BotFather и обнови настройки сервера.
